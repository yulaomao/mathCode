# 开发记录

## 1. 文档目的

本文档用于说明本项目从原始互动页面到“基于豆包大模型的小学数学智能互动支持系统”的开发演进过程，突出生成式人工智能在需求拆解、界面生成、代码编写、接口设计和问题调试中的参与证据。

## 2. 项目起点

项目最初是一个围绕“三位数除以两位数”设计的互动网页，包含口算热身、算理探究、估算试商和竖式巩固四个核心模块。早期版本偏向课堂展示型课件，缺少统一的学习数据采集、AI 分析和持续问答能力。

## 3. AI 辅助开发方式

### 3.1 需求拆解阶段

- 使用生成式 AI 分析教学痛点与比赛要求。
- 将需求拆解为互动学习、实时学情、课堂总结、虚拟教师、多轮上下文、页面感知问答等功能单元。

### 3.2 界面与交互开发阶段

- 使用生成式 AI 生成页面结构、交互动效和样式初稿。
- 结合教学场景人工调整为“主舞台 + 驾驶舱 + 流程底栏 + 虚拟教师入口”的结构。
- 主要涉及文件：`index.html`、`style.css`、`script.js`

### 3.3 后端与接口开发阶段

- 使用生成式 AI 协助搭建 Flask 基础服务。
- 生成并迭代 `/api/health`、`/api/ai/class-summary`、`/api/ai/module-support`、`/api/ai/virtual-teacher` 等接口结构。
- 主要涉及文件：`app.py`

### 3.4 调试优化阶段

- 利用生成式 AI 协助定位上下文丢失、页面问答失效、旧进程占端口等问题。
- 参考多轮对话上下文管理最佳实践，完成结构化 `conversationHistory`、历史摘要压缩、`pageContext` 页面感知与本地回退机制。

## 4. 版本演进记录

### V1：互动学习原型

- 完成四个数学学习模块。
- 实现点击、按压、滑块、数字输入等互动方式。
- 形成星际主题的沉浸式视觉风格。

### V2：学情与总结能力接入

- 增加积分、连击、正确率、提示次数、学习时长等过程数据统计。
- 增加课堂总结页与模块完成状态展示。
- 形成完整课堂流程闭环。

### V3：后端服务与豆包接入

- 新增 Flask 服务与 `.env` 配置。
- 接入豆包大模型，支持课堂总结与模块导学分析。
- 保留本地规则回退，增强演示稳定性。

### V4：虚拟教师与语音输入

- 新增虚拟教师问答面板。
- 支持文本输入与语音转文字。
- 采用聊天流界面承载学生追问。

### V5：多轮连续对话与页面感知

- 引入结构化聊天历史，而非简单截断近几轮文本。
- 为短追问设计连续追问规则，如“乘8呢”“那第二步呢”。
- 新增 `pageContext`，让虚拟教师可以回答“当前页面怎么玩”“这个按钮做什么”等问题。
