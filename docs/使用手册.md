# 使用手册

## 1. 产品简介

“基于豆包大模型的小学数学智能互动支持系统”面向小学数学“三位数除以两位数”学习场景，整合互动学习、实时学情、虚拟教师和课堂总结功能。系统既可用于课堂教学，也可用于学生自主练习和课后追问。

## 2. 启动方式

### 2.1 本地完整模式

1. 启动 Flask 服务。
2. 浏览器访问 `http://localhost:3000`。
3. 可使用实时学情、虚拟教师、多轮问答等完整能力。

### 2.2 静态演示模式

1. 直接打开根目录中的 `index.html`。
2. 可体验四个互动学习模块和本地规则化提示。
3. 未接入后端时，涉及大模型能力的部分会自动回退。

## 3. 界面构成

### 3.1 顶部控制区

- 当前环节：显示正在学习的模块。
- 完成进度：显示已完成模块数。
- 教师模式：开启后显示更适合教师讲解的提示信息。
- 暂停：暂停当前互动过程。
- 语音：控制语音播报开关。
- 音效：控制互动音效开关。

### 3.2 主舞台

主舞台承载核心学习任务，共有五个模块：口算热身、算理探究、估算试商、竖式巩固、课堂总结。

### 3.3 右侧驾驶舱

- 实时学情：展示完成率、累计积分、最高连击、模块状态与教师建议。
- 虚拟教师：支持文本提问、语音转文字输入和连续多轮问答。

### 3.4 底部流程区与浮动入口

- 底部按钮用于切换模块。
- 右下角“虚拟教师”浮动入口可快速打开问答面板。

## 4. 主要功能操作说明

### 4.1 口算热身

1. 进入“口算热身”模块。
2. 选择“简单 / 普通 / 困难”难度开始。
3. 在倒计时内点击商等于目标值的气泡。
4. 每连续完成若干次正确作答，系统会刷新目标。

### 4.2 算理探究

1. 观察题目与能量仓库数量。
2. 使用加号、减号调整“每人分几个”。
3. 按住“发射能量”执行平均分配。
4. 直到仓库正好分完，完成当前题目。

### 4.3 估算试商

1. 进入“估算试商”模块。
2. 拖动滑块调整商的猜测值。
3. 观察“除数 × 商”的乘积变化。
4. 点击“启动引擎”，判断当前商是偏大、偏小还是合适。

### 4.4 竖式巩固

1. 根据题目进入对应竖式步骤。
2. 通过下方数字键盘输入结果。
3. 点击“确认”提交，必要时用“⌫”删除。
4. 跟随提示完成“试商、乘、减、落”全过程。

### 4.5 课堂总结

1. 完成多个模块后进入“课堂总结”页。
2. 查看学习报告、模块完成状态和课堂总结建议。
3. 可选择“返回学习模块”继续练习，或“重新开始整课”。

## 5. 虚拟教师使用说明

1. 点击右下角“虚拟教师”入口，或在右侧驾驶舱切换到“虚拟教师”标签。
2. 在输入框中直接提问。
3. 如设备与浏览器支持，可点击“语音转文字”进行输入。
4. 支持两类常见问法：
   - 学习问题：如“为什么先试 7”“这一步为什么这样算”。
   - 页面问题：如“当前界面的分配游戏怎么玩”“这个按钮是做什么的”。
5. 支持连续追问，系统会结合上文保持回答连贯。

## 6. 数据与记录说明

- 系统会实时更新积分、连击、完成率、提示次数和学习时长等信息。
- 课堂会话会自动保存到浏览器本地存储，便于继续演示与后续扩展。
- 课堂快照中包含模块状态、过程数据和 AI 结果，可用于教学复盘。

## 7. 常见问题

### 7.1 语音转文字无法使用

- 请确认浏览器支持 `SpeechRecognition` / `webkitSpeechRecognition`。
- 请允许页面使用麦克风。

### 7.2 AI 回答变成本地提示

- 说明本地未配置有效 `ARK_API_KEY`，或后端接口调用失败。
- 此时系统会自动回退为本地规则回答，不影响基本演示。

### 7.3 本地服务无法打开

- 请确认 Flask 服务已启动。
- 如端口 3000 被占用，请关闭重复的 Python 监听进程后重试。
