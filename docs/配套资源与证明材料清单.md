## 4. 功能核验示例

### 4.1 页面玩法问答核验

示例问题：`当前界面的分配游戏怎么玩？`

核验结果要点：

- 能识别当前页面为“算理探究”
- 能说明玩法、主要按钮和当前状态
- 结果来源可标识为“页面上下文规则”或豆包模型结果

### 4.2 连续追问核验

示例问题链：

1. `我在做156÷21，商7是怎么试出来的？`
2. `乘8呢？`

核验结果要点：

- 后一问能沿用前一轮算式上下文
- 能回答 `21×8=168，超过156，因此8偏大`
- 结果来源可标识为“连续追问规则”或豆包模型结果

### 4.3 健康检查核验

访问 `http://localhost:3000/api/health`，可核验：

- 服务是否正常运行
- 是否检测到 API Key
- 当前模式是豆包模式还是本地规则模式
