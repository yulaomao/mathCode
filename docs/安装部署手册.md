# 安装部署手册

## 1. 适用范围

本文档用于指导本项目在本地电脑上完成安装、运行与基础校验，适用于比赛演示、课堂试用和校内复现。

## 2. 环境要求

### 2.1 基础环境

- 操作系统：Windows 10/11、macOS 或 Linux
- Python：建议 3.10 及以上
- 浏览器：推荐 Chrome、Edge 等 Chromium 内核浏览器
- 网络：如需调用豆包大模型，需具备可访问火山方舟服务的网络环境

### 2.2 项目文件

请确保仓库中至少包含以下文件：

- `index.html`
- `script.js`
- `style.css`
- `app.py`
- `requirements.txt`
- `.env.example`

## 3. 部署方式一：静态演示模式

适用于只演示前端互动流程、不依赖后端大模型的场景。

1. 将项目文件复制到本地目录。
2. 直接用浏览器打开 `index.html`。
3. 可体验口算热身、算理探究、估算试商、竖式巩固、课堂总结等前端功能。
4. 未配置后端时，系统中的 AI 能力会回退为本地规则提示。

## 4. 部署方式二：完整本地部署模式

适用于比赛演示、接口调试和完整体验豆包能力的场景。

### 4.1 创建虚拟环境

```bash
python -m venv .venv
```

Windows 激活方式：

```bash
.venv\Scripts\activate
```

### 4.2 安装依赖

```bash
pip install -r requirements.txt
```

### 4.3 配置环境变量

1. 将 `.env.example` 复制为 `.env`。
2. 填写以下字段：

```env
PORT=3000
ARK_API_KEY=你的豆包或火山方舟API密钥
ARK_MODEL=doubao-seed-2-0-pro-260215
```

### 4.4 启动服务

```bash
python app.py
```

### 4.5 打开系统

浏览器访问：

```text
http://localhost:3000
```

## 5. 部署校验

### 5.1 健康检查

访问：

```text
http://localhost:3000/api/health
```

若服务正常，可看到包含 `ok`、`hasApiKey`、`mode` 等字段的 JSON。

### 5.2 页面检查

- 首页能正常打开。
- 各模块可切换。
- 右下角“虚拟教师”入口可点击打开。
- 在未配置密钥时，系统仍能返回本地规则提示。

### 5.3 AI 问答检查

建议用以下问题做演示验证：

- “当前界面的分配游戏怎么玩？”
- “为什么先试 7？”
- “乘 8 呢？”

## 6. 常见问题与排查

### 6.1 端口 3000 被占用

- 说明已有 Python 进程占用该端口。
- 关闭旧进程后重新执行 `python app.py`。
- 比赛演示前建议只保留一个 Flask 监听进程。

### 6.2 未检测到 API Key

- 终端会提示未检测到 `ARK_API_KEY`。
- 此时系统仍可运行，但 AI 结果会回退为本地规则。

### 6.3 语音输入不可用

- 请使用支持语音识别的浏览器。
- 请允许页面使用麦克风。

### 6.4 大模型接口返回失败

- 检查 `.env` 中的 `ARK_API_KEY` 和 `ARK_MODEL` 是否正确。
- 检查网络环境是否可访问火山方舟服务。
- 检查后端终端输出是否有报错信息。
