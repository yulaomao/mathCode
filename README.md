# 基于豆包大模型的小学数学智能互动支持系统

本项目基于现有“星际数学探险：三位数除以两位数”互动页面升级而来，定位为服务课堂教学、自主练习与课后辅导的小学数学智能互动支持系统。系统保留原有四个核心学习模块，并新增学习过程数据采集、AI课堂分析、虚拟教师问答、课堂记录导出和基于 Python + Flask 的本地豆包代理服务。

## 核心功能

- 口算热身：限时口算互动，支持正确率统计和课堂热身诊断。
- 算理探究：通过分配动画理解整十数除法的平均分模型。
- 估算试商：通过推力滑块判断商偏大或偏小，沉淀试商表现数据。
- 竖式巩固：通过分步输入、语音提示和错因统计强化“试商、乘、减、落”。
- 课堂总结：展示完成率、学习时长、模块状态和 AI 课堂复盘。
- AI 课堂分析：支持调用豆包大模型生成学生总结、教师建议、下一步推荐和风险提示。

## 运行方式

### 方式一：本地规则建议

1. 直接打开 `index.html`。
2. 系统仍可使用课堂数据采集、总结页与导出功能。
3. 点击“生成AI建议”时，如果没有本地服务，会回退为本地规则建议。

### 方式二：本地 Flask 豆包代理服务

1. 将 `.env.example` 复制为 `.env`。
2. 填入 `ARK_API_KEY` 和 `ARK_MODEL`。
3. 安装依赖：

```bash
pip install -r requirements.txt
```

4. 运行：

```bash
python app.py
```

5. 浏览器访问：

```text
http://localhost:3000
```

6. 前端点击“生成AI建议”时会调用 `/api/ai/class-summary`，由 Flask 代理服务转发到豆包接口。

### 可选：虚拟环境

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 环境变量

- `PORT`：本地服务端口，默认 3000。
- `ARK_API_KEY`：豆包/火山方舟 API Key。
- `ARK_MODEL`：大模型名称，默认 `doubao-seed-2-0-pro-260215`。

## 参赛材料建议

- 使用 `docs/ai-prompts.md` 作为提示词工程附件。
- 使用“导出课堂记录”生成 JSON 作为课堂试用数据原始材料。
- 录屏时建议从教师模式出发，演示课堂数据、AI 建议和课堂总结页。

## 主要文件

- `index.html`：课堂主界面。
- `script.js`：前端状态管理、课堂数据采集与 AI 请求逻辑。
- `style.css`：视觉与响应式布局。
- `app.py`：基于 Flask 的本地豆包代理服务与静态文件服务。
- `requirements.txt`：Python 依赖清单。
- `docs/ai-prompts.md`：比赛可复现的提示词设计说明。
